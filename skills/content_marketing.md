# Skill: Content Marketing Generation

## Description
Generate comprehensive content marketing materials including blog posts, articles, and email campaigns.

## Input
- topic: string
- targetAudience: string
- contentType: 'blog' | 'article' | 'email' | 'newsletter'
- keywords: string[]
- wordCount: number

## Output
- title: string
- content: string
- metaDescription: string
- seoKeywords: string[]
- summary: string
